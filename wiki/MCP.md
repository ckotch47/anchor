# MCP

Anchor можно использовать через MCP по `stdio` как тонкий транспорт поверх того же ядра.

Что важно:

- MCP не заменяет CLI-контракт, а переиспользует те же use-cases
- транспорт запускается командой `anchor mcp`
- для прямого запуска есть `anchor-mcp`
- ответы остаются структурированными и token-light
- основной контракт по-прежнему живёт в CLI и `docs/`

Когда это нужно:

- если агент умеет MCP нативно
- если хочется подключить Anchor без web API
- если нужен один локальный инстанс на пользователя

Когда это не обязательно:

- если достаточно обычного CLI
- если интеграция уже строится поверх shell/stdio без MCP-typed schema
