# Wiki export

Эта папка содержит версию документации, удобную для переноса в GitHub Wiki.

Использование:

- как источник для отдельного GitHub Wiki repo
- как короткое операторское руководство
- как человеческий слой поверх канонических `docs/`
- как место, где описаны оба пути установки: editable-install и wheel
- как место, где лежит пример скилла для подключения агента

Главная страница вики: [Главная](./Главная.md)

Канонический источник по-прежнему остаётся здесь:

- `docs/`
- `CHANGELOG.md`
- `README.md`
