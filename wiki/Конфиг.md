# Конфиг

Конфиг хранится в пользовательской папке.

## Пути

- config: `~/.qatoria/anchor/config.toml`
- database: `~/.qatoria/anchor/anchor.sqlite3`

## Основные секции

- `[runtime]`
  - default view
  - default project
  - default budget
  - retry and lock behavior
  - offline-only mode
- `[provider]`
  - base URL
  - API key env
  - embedding model
  - rerank model
- `[vector]`
  - dimension
  - distance
  - chunk size
  - chunk overlap
- `[metadata]`
  - entity schemas for notes, tasks, history, files
- `[links]`
  - allowed relation types for document links
- `[profiles.*]`
  - per-profile overrides

## Принципы

- один TOML-файл
- command flags могут перекрывать config
- provider URL может указывать на локальный OpenAI-compatible endpoint
- offline-only mode отключает генерацию
- metadata schemas должны совпадать с тем, что реально пишет агент
- links relation types лучше хранить как явный whitelist

## Базовые команды

```bash
anchor config init
anchor config get --profile default
anchor config set --section runtime --key default_view --value full
```

## Пример

Смотри `config.example.toml` в корне репозитория.
