# Файлы

Слой файлов индексирует локальные репозитории.

## Что индексируется

- текстовые файлы в заданных roots
- файлы, которые не попали под ignore
- файлы меньше лимита по размеру
- только если файл реально читабелен как текст

## Что пропускается

- бинарники
- ignore paths
- vendor/build output
- файлы, которые не читаются как UTF-8

## Чанкинг

- Python: по границам `def` / `class`
- Markdown: по заголовкам `#`
- всё остальное: sliding window по строкам
- чанки должны быть rebuildable
- batch write лучше, чем держать всё дерево в памяти

## Жизненный цикл индекса

- индексирование идёт батчами
- метаданные файла живут в SQLite
- retrieval chunks строятся из текста файла
- исчезнувшие файлы чистятся из индекса

## Контракт list

- `files list` пагинируется курсором
- cursor завязан на UUIDv7 `document_id`
- вывод по умолчанию компактный

## Контракт search

- `files search` смешивает lexical, vector и rerank, если они доступны
- результаты дедуплицируются по файлу
- ответ режется по token budget
- path и path-prefix лучше нормализовать до одного правила, чтобы не плодить дубли
