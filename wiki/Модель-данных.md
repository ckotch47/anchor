# Модель данных

## Общий позвоночник

Anchor использует общую таблицу `documents` как канонический корень для текстовых сущностей.

## Доменные таблицы

- `notes`
- `tasks`
- `history_entries`
- `indexed_files`

## Derived tables

- `document_chunks`
- `file_chunks`
- `chunk_embeddings`
- `index_states`
- `document_links`
- `document_tags`

## Правила идентификаторов

- primary ids — UUIDv7 строки
- chunk ids — UUIDv7 строки
- correlation ids — UUIDv7 строки
- parent/blocker ссылки тоже UUIDv7

## Project и metatags

- `project` дублируется в каждую доменную сущность
- `metatags` хранится как SQLite JSON text
- list/search всегда должны сначала сужать scope по project

## Retrieval rules

- canonical text живёт в доменных таблицах
- chunks строятся из canonical text
- embeddings считаются из chunks
- derived data должно быть rebuildable из canonical rows

## Жизненный цикл

- `pending`
- `stale`
- `ready`
- `error`
