# Подключение

Подключение в Anchor означает не сеть, а приведение локального инстанса в рабочее состояние.

## 1. Выбрать проект

Почти все команды работают в контексте `--project`.

```bash
./.venv/bin/anchor notes list --project repo-a
```

Если `--project` не указан, берётся значение из конфига.

## 2. Настроить провайдера

Для embeddings и rerank нужен OpenAI-compatible endpoint.

Пример:

```toml
[provider]
base_url = "http://192.168.3.15:11434"
embedding_model = "nomic-embed-text:latest"
rerank_model = "awenleven/Qwen3-Reranker-4B:Q4_K_M"
```

## 3. Настроить vector-параметры

```toml
[vector]
dimension = 1536
distance = "cosine"
chunk_size = 400
chunk_overlap = 50
```

## 4. Подключить профиль

Профили лежат в том же TOML-файле.

```bash
./.venv/bin/anchor config get --profile default
./.venv/bin/anchor config set --section runtime --key default_view --value compact
```

## 5. Проверить готовность

```bash
./.venv/bin/anchor health
./.venv/bin/anchor config get --profile default
```

## 6. Подключить MCP при необходимости

Если агент умеет MCP нативно, можно запускать:

```bash
./.venv/bin/anchor mcp
```

Для прямого запуска stdio-обвязки есть отдельная команда `anchor-mcp`.

Если нужен только CLI, MCP можно не использовать.
