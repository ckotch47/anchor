# Установка

Anchor рассчитан на локальный запуск. Есть два нормальных пути установки:

- для разработки - editable-install в `.venv`
- для обычной установки - собрать wheel и поставить готовый пакет

## Требования

- Python 3.11+
- SQLite
- доступ к репозиторию с кодом

## Быстрый старт

```bash
python3 -m venv .venv
.venv/bin/pip install -e .
```

После этого CLI доступен так:

```bash
./.venv/bin/anchor --help
./.venv/bin/anchor health
```

## Установка собранного пакета

Если нужен не dev-режим, а обычная установка, собирай wheel через `make build` и ставь его как пакет:

```bash
make build
pip install dist/*.whl
```

Если нужна изоляция по пользователю, удобно ставить через `pipx`:

```bash
pipx install dist/*.whl
```

## Что создаётся локально

- файл конфига в `~/.qatoria/anchor/config.toml`
- база данных в `~/.qatoria/anchor/anchor.sqlite3`

## Инициализация

Первый запуск CLI поднимет нужные миграции автоматически.

Если хочется сделать это явно:

```bash
./.venv/bin/anchor db migrate
```

Для обслуживающей очистки:

```bash
./.venv/bin/anchor db compact
```

## Проверка установки

```bash
./.venv/bin/anchor health
./.venv/bin/anchor config get
```

Если `health` проходит, значит локальный контур готов к работе.

## Когда какой способ брать

- `pip install -e .` - если ты меняешь код
- `make build` + `pip install dist/*.whl` - если ставишь уже собранную версию
- `pipx install dist/*.whl` - если хочешь изолированную установку без ручного управления виртуальным окружением
