# Anchor Wiki

Это операторская вики проекта Qatoria Anchor.

Здесь не канонический источник правды, а удобная человеческая оболочка поверх `docs/`:

- один пользователь, один локальный инстанс
- одна SQLite-база
- без обязательного web API
- MCP по `stdio` как опциональный транспорт
- retrieval-first с первого дня

- быстро объяснить людям и агентам, как пользоваться инструментом

- не заставлять читать все ADR подряд
- сохранить совпадение с актуальной CLI-реализацией
