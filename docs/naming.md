# Naming

## Canonical names

- Brand: `Qatoria`
- Product: `Anchor`
- CLI binary: `anchor`
- Python package: `anchor`
- Config root: `~/.qatoria/anchor`

## Rationale

- `Anchor` reflects the core job of the tool: be a stable grounding point for an agent's local context.
- `Qatoria` stays as the umbrella brand from the domain.
- The CLI name stays short and human-friendly.

## Rules

- Use `Anchor` in product-facing docs.
- Use `anchor` for executable and package naming.
- Avoid `agentctl` and `cli_tool_for_agents` as canonical names.
- If any transitional path still uses the old names, treat them as temporary implementation details only.
